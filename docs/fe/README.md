# Frontend documentation

Chỉ mục tài liệu Flutter Android/iOS. Mỗi feature phải có file riêng và cập nhật
liên kết tại đây.

Tài liệu frontend cần mô tả màn hình, navigation, state management, use case,
domain model, repository contract, Supabase/local adapter, trạng thái lỗi,
accessibility, bảo mật dữ liệu trên thiết bị và kiểm thử.
