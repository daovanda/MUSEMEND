# Android Internal Testing (deprecated)

**Trạng thái:** `deprecated`
**Cập nhật:** 2026-09-06

Phương án Google Play Internal Testing chưa được dùng do hiện tại chưa đăng ký
Play Console. Android QA chuyển sang phát hành APK release qua GitHub Releases.

Thiết kế và cách cấu hình hiện tại nằm tại
[Android QA Release qua GitHub Releases](./android-qa-release.md). Khi dự án sẵn
sàng trả phí Play Console, có thể bổ sung lại bước upload AAB mà không đổi
package ID hoặc signing lineage.
